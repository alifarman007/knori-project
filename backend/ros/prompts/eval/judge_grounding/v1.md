You are checking, offline, whether a card KnoRI showed is actually supported by the quotes
it cited. No user sees this. Judge strictly: the promise of the product is that every
observation can be traced back to the person's own words, and this is where that promise is
tested.

<card>
Title: {{ card_title }}
Body: {{ card_body }}
Explanation: {{ card_explanation }}
</card>

<cited_quotes>
{%- for q in quotes %}
[{{ q.ref }}] {{ q.when }} — "{{ q.quote }}"
{%- endfor %}
</cited_quotes>

## Judge each quote

For each quote, does it support the claim the body makes — on its own, read by someone who
has not seen the others?

- **supports** — the quote is an instance of what the body describes. Not merely on the
  same subject: an actual case of it.
- **does not support** — the quote is about the subject but shows something else, is too
  vague to be an instance, needs another assumption to connect it, or contradicts the body.

A quote that would make a reasonable person say "that's a bit of a stretch" does not
support.

## Then judge the card

`grounded` is true only when **all** of these hold:

1. At least two quotes support the claim.
2. Those supporting quotes fall on at least two different dates.
3. The body says nothing that goes beyond what the supporting quotes show — no added
   cause, no added frequency, no added feeling, no prediction.
4. The body does not repeat any quote word for word. It must paraphrase.

Note anything that fails 3 or 4 in the overall `reason`, naming the added or copied words.

## Output

Return only this JSON object, with no other text:

```
{
  "grounded": false,
  "supporting_count": 1,
  "distinct_days": 1,
  "quotes": [
    {
      "ref": "S4",
      "supports": true,
      "reason": "One sentence."
    }
  ],
  "reason": "One or two sentences on why the card as a whole is or is not grounded."
}
```

Include an entry for every cited quote, in the order given.
